# Plans

- **Status:** accepted · **Verified:** 2026-10-31

A small change needs no written plan. Work that spans more than one sitting, or that future agents must
understand, gets an execution plan in `docs/exec-plans/active/`:

```markdown
# <What this achieves>

## Goal           one paragraph: the outcome, and how you will know
## Progress       a checklist, kept current as work happens
## Decision log   dated entries: what was decided, why, what was rejected
```

The docs lint requires `## Progress` and `## Decision log`. Move a finished plan to `completed/`. File
anything you chose not to do in the [debt tracker](exec-plans/tech-debt-tracker.md).

See the [plan index](exec-plans/index.md).
