prove every gate on one real slice: the page shows the planets at their true positions now, checked
against JPL.

## Decision log

**2026-10-31. Audience: educators and students.** Chosen by the project owner.

**2026-10-31. TypeScript only, with our own SPK reader.** One toolchain, so Effect's rules apply
everywhere. The prototype used Python's jplephem. The reader is small and checked against Horizons and a
published eclipse. The golden test passing against the real kernel is what makes this safe.

**2026-10-31. Keep the full Vector and Victoria stack per worktree.** The agent recommended cutting it
because the app is a 6-second batch job and a static page. The project owner chose to keep it, following
the article. See [the design note](../../design-docs/observability.md).

**2026-10-31. TypeScript 6.0, not 7.** TypeScript 7 is current, but typescript-eslint and Gyral's
`check_snippet` both require 6.x.

**2026-10-31. Effect in the browser.** Its Schema and typed errors guard the same boundaries as on the
worker. The whole page is 209 KiB gzipped, under a 240 KiB budget; Three.js is most of it.

**2026-10-31. The semantic-html skill is pinned at the remote's head.** A local copy had one commit that
was not pushed, so a submodule could not reference it.

**2026-10-31. Tests after the code, for the workflows.** `build-tile`, `verify-tile`, `load-sky` and the
HTTP adapters were written before their tests, against the TDD skill. The coverage gate exposed it. To
prove the late tests can fail, six lines were broken on purpose, including the publish gate and the tile
hash check; the suite caught all six.

**2026-10-31. Ports below 32768.** The first choice, 41000 and up, sits in Linux's ephemeral range, and
a real collision stopped `pnpm dev`.

**2026-10-31. `pnpm dev:stop`.** A signal sent to `pnpm dev` stopped pnpm alone and stranded four
containers and the web server. The command signals the process that owns cleanup.
