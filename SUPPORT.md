# Getting help

| You want to | Go here |
|---|---|
| Ask a question, or share how you used this with a class | [Discussions](https://github.com/mikezupper/learn-solar-system/discussions) |
| Tell us what would help in your classroom | [Classroom feedback](https://github.com/mikezupper/learn-solar-system/issues/new?template=classroom_feedback.yml) |
| Report a number that looks wrong | [Accuracy report](https://github.com/mikezupper/learn-solar-system/issues/new?template=accuracy_report.yml) |
| Report something broken | [Bug report](https://github.com/mikezupper/learn-solar-system/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/mikezupper/learn-solar-system/issues/new?template=feature_request.yml) |
| Report a security problem | Privately, as [SECURITY.md](SECURITY.md) explains. Please do not open an issue |

Before you ask, these may already answer your question:

- [README.md](README.md): what this is, the science, and how it is built.
- [CONTRIBUTING.md](CONTRIBUTING.md): setting up, testing, and common problems.
- [The guide for teachers](docs/guides/teaching.md): using the page with a class.
- [The deployment guide](docs/guides/deployment.md): hosting your own copy.

This is a volunteer project with no support contract, so answers may take a while.
